## 0. 三条先决规则（比找文档更重要）

1. **状态管理只能用 V2**：`@ComponentV2` / `@Local` / `@Param` / `@Event` / `@ObservedV2` / `@Trace`。V1 与 V2 **不得混用**。详见 `02-编码规约.md`。
2. **设计取值只有一个来源**：`entry/src/main/ets/utils/Theme.ets`。页面里出现裸色值 `'#RRGGBB'` 或裸尺寸是**拒绝合并**的理由。
3. **鸿蒙 7 的新 UI 能力默认不启用**（本项目 `targetSdkVersion = 6.0.2(22)`）—— 见 `11-鸿蒙7新UI能力.md` 开头的版本门槛说明。

## 4. 与专家技能的协作

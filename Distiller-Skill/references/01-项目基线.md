### 1.1 本机环境（**各自探测，不要照抄别人的值**）

上面那张表是**项目事实**，三台机器一致。这一小节是**因人而异**的：SDK 装在哪、装的是哪个版本、有没有连设备、shell 是哪一个，**每台机器都可能不同**，而且**会随升级漂移**。
本文档不替你写死这些值 —— 动手前自己跑一遍下面这组命令，把结果当成你那台机器的现状。

| 要探什么 | 命令 | 怎么看结果 |
| :-- | :-- | :-- |
| 工具链版本 | `devecocli --version` | 就是 `devecocli` 的版本号；**升级过就与本文其它地方记的值不同，以你这条输出为准** |
| 有没有连真机 | `devecocli device list` | 打印 `No active devices.` = 这台机器上没连真机。**这是正常状态，不等于团队没有真机** |
| 本机模拟器 | `devecocli emulator list` | 列出模拟器名 / `Status` / `OS Version`。`stopped` 表示没启动，需要时自己 `devecocli emulator start <name>` |
| shell 是不是 PS 5.1 | `$PSVersionTable.PSVersion.ToString()` | 主版本 `5` → 适用 `05-已知坑.md` T1 的 BOM 规则；主版本 `7+` → 通常不适用（**未实测**，拿不准就照样跑一次 BOM 修复，无害） |
| 有没有独立 `pwsh.exe` | `Get-Command pwsh -ErrorAction SilentlyContinue` | **有输出** = 装了 PowerShell 7；**输出为空** = 只有 `powershell.exe` |
| `$env:DEVECO_SDK_HOME` | `$env:DEVECO_SDK_HOME` | ⚠️ 见下面的坑：**这个变量不一定指向 HarmonyOS SDK 根目录** |

**SDK 根目录怎么找**（`devecocli` **没有**任何查 SDK 路径的子命令 —— `config` / `doctor` / `info` / `sdk` / `env` 都不是有效子命令；`devecocli --help` 的完整命令表里没有这一项）。只能走文件系统，判据是 **`sdk\default\sdk-pkg.json` 这个文件**：

```powershell
# 候选根 = DEVECO_SDK_HOME 的父目录 + 两个常见安装位；再按「父目录名必须是 default」过滤
$roots = @(
  $(if ($env:DEVECO_SDK_HOME) { Split-Path $env:DEVECO_SDK_HOME -Parent }),
  "$env:ProgramFiles\Huawei",
  "$env:LOCALAPPDATA\Huawei"
) | Where-Object { $_ -and (Test-Path $_) }

Get-ChildItem $roots -Recurse -Filter sdk-pkg.json -Depth 5 -ErrorAction SilentlyContinue |
  Where-Object { $_.Directory.Name -eq 'default' } |
  Select-Object -ExpandProperty FullName
# 命中的那一行去掉 \sdk-pkg.json 就是 SDK 根；同目录的 sdk-pkg.json 里有 apiVersion / displayName / version / releaseType
```

> [!warning] 两个实测过的坑，别踩
> 1. **`sdk-pkg.json` 会撞名。** `$env:DEVECO_SDK_HOME` 下面（`system-image\HarmonyOS-*\phone_all_x86\`）**每个模拟器镜像里也有一个**同名文件，但它描述的是**模拟器系统镜像**、不是 SDK —— 所以必须加 `Where-Object { $_.Directory.Name -eq 'default' }` 这层过滤。
> 2. **`$env:DEVECO_SDK_HOME` ≠ SDK 根。** 生成副本的机器上它是 `…\DevEco Studio beta\sdk`，里面**只有 `licenses` 与 `system-image`**，没有 `default\` —— 所以「打印 `$env:DEVECO_SDK_HOME` 再看它下面的 `default`」这个两步法**在那台机器上直接失效**；真正的 SDK 在它的**兄弟目录**下（`…\DevEco Studio beta\DevEco Studio\sdk\default`）。上面命令里的 `Split-Path … -Parent` 就是为这件事。

> [!note] 生成这份副本时，这台机器探到的值（**仅供参考，不代表你的机器**）
> `devecocli` 1.3.4 · `device list` = `No active devices.` · 模拟器 `Pura 90`(6.1.1(24)) 与 `Pura X View`(7.0.0(26.0.0) Beta2) 均 `stopped` · PowerShell `5.1.x`（无 `pwsh`）· `$env:DEVECO_SDK_HOME` 指向系统镜像目录（非 SDK 根）· SDK 根为 `…\DevEco Studio\sdk\default`，其 `sdk-pkg.json` 报 `apiVersion "26"` / `displayName "HarmonyOS 26.0.0"` / `version "26.0.0.32"` / `releaseType "Beta2"`。
> 这行的**唯一用途**是让你知道「差异长什么样」，**不是给你当自己机器的现状**。

| 二进制白名单 | `*.png/jpg/jpeg/gif/webp/ico/pdf/hap/har/so/dll/exe/ttf/otf` 标 `binary`，不做行尾转换，也不让 git 自行判定 | `.gitattributes:8-21` |

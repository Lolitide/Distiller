# OpenHarmony平台Flutter三方库适配情况

## 介绍

本文档汇总了OpenHarmony平台适配的三方库情况，包括已适配的三方库、已适配的纯dart库以及正在适配中的三方库。这些库覆盖了权限管理、UI组件、设备信息、位置服务、媒体处理等多个功能领域，为开发者提供了丰富的选择。

## 目录

- [1、OpenHarmony平台已适配三方库](#1openharmony平台已适配三方库)

  本部分列出了已成功适配到OpenHarmony平台的三方库，这些库经过了适配和测试，能够在OpenHarmony设备上正常运行。每个库都提供了不同版本的适配情况，包括3.7、3.22、3.27和3.35版本的推荐版本。
  
- [2、OpenHarmony平台适配中的三方库](#2openharmony平台适配中的三方库)!

  本部分列出了正在适配过程中的三方库，这些库尚未完全适配到OpenHarmony平台，但正在积极开发和测试中。


## 使用方式

> [!TIP] 当前三方库引入了TAG进行版本隔离，例如 0.4.2-ohos-1.0.0-beta.1，代表原库版本是 0.4.2，是鸿蒙化后的第一个版本，每个仓库中均有框架版本TAG对应表，可进行配套使用

```yaml
dependencies:
  r_upgrade:
    git:
      url: https://gitcode.com/CPF-Flutter/fluttertpc_r_upgrade.git
      # ref: 0.4.2-ohos-1.0.0-beta.1
      ref: TAG    # 请根据下方TAG版本对应表选择TAG
```

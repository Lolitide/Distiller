# Performance Docs Conventions

- Documents are bilingual: Chinese (`.md`) and English (`.en.md`). Always edit both versions together.
- `README.md` and `README.en.md` each have their own document directory table. Keep the two tables in sync (same documents, same order).
- Do not mix languages within a table: the Chinese README (`README.md`) lists only Chinese documents (`.md`); the English README (`README.en.md`) lists only English documents (`.en.md`).
- The document column shows the document title (the `#` heading of each file), linked to the file.
- Cross-link to the other-language README as a single line outside the table (e.g. `> 英文版文档见 [README.en.md](README.en.md)`), never as a table row.

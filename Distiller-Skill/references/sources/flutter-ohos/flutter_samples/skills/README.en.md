# AI Skills

This directory contains AI Skills that accompany the Flutter OHOS documentation, used to assist with performance analysis and crash investigation.

## Skills

| Skill | Description |
|-------|-------------|
| [flutter-ohos-insight](./flutter-ohos-insight/SKILL.md) | Analyze `.insight` trace packages generated by DevEco Studio Profiler to diagnose Flutter OHOS performance issues (jank, first-frame delay, UI thread stalls, GPU bottlenecks, etc.) |
| [ohos-flutter-crash-analyzer](./ohos-flutter-crash-analyzer/SKILL.md) | Analyze Flutter OHOS app crashes, parse native stacks, identify root causes, and generate fix recommendation reports |

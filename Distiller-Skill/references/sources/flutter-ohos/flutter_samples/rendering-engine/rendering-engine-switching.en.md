# Flutter OH Impeller and Skia Rendering Engine Switching Guide

This document describes how to switch between the Impeller and Skia rendering engines in a Flutter OH application through a configuration file.

---

## 1. Background

Flutter OH currently supports two rendering modes, Impeller (Vulkan backend) and Skia, and whether Impeller is enabled can be controlled through a configuration file.

| Rendering Engine | Supported Version |
| ------------ | ---------------------- |
| **Impeller** | Flutter OH 3.22.0 and above |
| **Skia**     | Flutter OH 3.7.12 and above |

---

## 2. Configuration File Location

The rendering mode is controlled by a configuration file under the project's `ohos` directory: `ohos/entry/src/main/resources/base/profile/buildinfo.json5`.

This file is a rendering configuration file automatically generated by the Flutter OH project and contains the `enable_impeller` field.

---

## 3. Switching Steps

**Step 1:** Enable Impeller (default mode). Edit `buildinfo.json5` and set the value of `enable_impeller` to `"true"`:

```json5
{
  "string": [
    {
      "name": "enable_impeller",
      "value": "true"
    }
  ]
}
```

**Step 2:** Switch to Skia rendering mode. Edit `buildinfo.json5` and set the value of `enable_impeller` to `"false"`:

```json5
{
  "string": [
    {
      "name": "enable_impeller",
      "value": "false"
    }
  ]
}
```

> **Note**: After modifying the configuration, you need to rebuild the project for the change to take effect; hot reload alone will not switch the rendering engine.

### Project Initialization Notes

New projects have `Impeller` enabled by default. For existing projects, you can copy the `buildinfo.json5` file to the `ohos/entry/src/main/resources/base/profile/` path of the project directory and modify the `value` to implement the switch. If the switch is not added, `Impeller` rendering mode is enabled by default.

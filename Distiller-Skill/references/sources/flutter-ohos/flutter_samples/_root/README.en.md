# Flutter Samples
## Introduction
This repository extends Flutter's  [samples](https://github.com/flutter/samples/) to provide OpenHarmony platform adaptation examples and supporting documentation, covering app development, platform capability integration, and engineering practices. Developers can quickly get started with Flutter on OpenHarmony and use these examples as references for implementation and validation.

## How to Run a Sample Code

1. Build the Flutter engine that is compatible with OpenHarmony. For details, see https://gitcode.com/openharmony-sig/flutter_engine/blob/master/README_EN.md.
2. Download the Flutter SDK that is compatible with OpenHarmony and configure the environment. For details, see https://gitcode.com/openharmony-sig/flutter_flutter/blob/master/README_EN.md.
3. Go to the sample directory, for example, **flutter_music_player**, and run `flutter run --local-engine=<path of the OpenHarmony-compatible Flutter engine's build product>`.

## FAQs
### How do I use Dart code to determine whether the current platform is ohos?
```dart
import 'package:flutter/foundation.dart';

bool isOhos() {
  return defaultTargetPlatform == TargetPlatform.ohos;
}
```

# Flutter ETS API Documentation v1.0.0

> This directory is the API reference for the ArkTS APIs exposed by the Flutter **OpenHarmony adaptation layer** (package name `@ohos/flutter_ohos`), not the Dart API of the Flutter framework itself.

## Reading Guide

- To get started, read [flutter-ohos-api-guide.en.md](./flutter-ohos-api-guide.en.md) first: it is organized around the core objects (`FlutterAbility` / `FlutterEngine` / `FlutterPlugin` / `MethodChannel` / `PlatformView`, and so on), with usage examples and lifecycle notes.
- To look up specific class/method signatures, use the table below to go to the `README.md` of the corresponding subdirectory.

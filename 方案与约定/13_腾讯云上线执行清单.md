
```ini
QQBOT_SECRET=<你的 Bot AppSecret>

QQBOT_CONSOLE_HOST=127.0.0.1
QQBOT_CONSOLE_PORT=8730
QQBOT_CONSOLE_USER=admin
QQBOT_CONSOLE_PASSWORD=<强口令>

QQBOT_PUBLIC_HOST=127.0.0.1
QQBOT_PUBLIC_PORT=8731
QQBOT_RELAY_KEY=<16字节hex>

QQBOT_DEV_INGEST=0
QQBOT_GROUP_COLLECT=0
QQBOT_TENANTS=/opt/zhiliao/app/tenants.json
QQBOT_MAX_TENANTS=12
QQBOT_LLM_WORKERS=1
QQBOT_LLM_VISION=0

QQBOT_PUSH_SA=/opt/zhiliao/app/service_account.json
QQBOT_PUSH_INCLUDE_TEXT=0
```


## F. 域名 + 备案（个人主体，APP 类型）

> 个人账号**不能生成备案授权码**，也不需要；直接用这台轻量作为备案资源。

1. **买域名并实名**：腾讯云域名注册 → 域名持有者用**同一个人**（= 账号实名 = 备案主体）。
2. 腾讯云控制台 → **ICP 备案** → **首次备案** → 服务类型选 **APP**（不是网站）。
3. 主体信息：**个人**（身份证、手机、邮箱、应急电话）。
4. 服务信息：
   - 云资源选 **轻量应用服务器 `lhins-azqlfoys`**（系统自动带出 IP）；
   - APP 名称：**知了 · 校园信息助手**（必须与 AGC 上架名、安装后桌面名**完全一致**；中间点 `·` 与空格不要一处有一处没有）；
   - 包名 / 公钥 / 证书指纹：用 AGC「证书、APP ID 和 Profile」里的**正式发布证书**；
   - 后台域名：你买的域名（如 `api.zhiliao.xxx`）；
   - 内容分类：**工具 / 效率**；
   - 是否涉及前置审批：**否**（工具类一般不需要）。
5. 上传材料 → 人脸核验 → 提交。
6. 腾讯云初审（1–3 工作日，**电话保持畅通**）→ 短信核验 → 陕西省通信管理局（法定 20 工作日）。
7. 拿到备案号后：
   - App「设置 → 关于」展示备案号 + 链接 `https://beian.miit.gov.cn`；
   - 回 AGC 提交版本时填备案号；
   - **30 天内**完成公安联网备案（全国互联网安全管理服务平台 → APP 业务 → 新增 APP）。

**备案期间纪律**：
- 不要用域名对外提供 80/443 服务（未备案会被拦）；
- 用 IP + SSH 隧道联调；
- 域名持有者、备案主体、腾讯云账号实名、App 开发者，**尽量同一个人**。

## G. 备案通过后：开 443 + 监控 + 备份

```bash
# Caddy（官方源）
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install -y caddy

sudo tee /etc/caddy/Caddyfile >/dev/null <<'EOF'
api.zhiliao.xxx {
    encode gzip
    request_body { max_size 4MB }
    reverse_proxy 127.0.0.1:8731
    header {
        Strict-Transport-Security "max-age=31536000"
        X-Content-Type-Options nosniff
        -Server
    }
}
EOF
sudo systemctl reload caddy
```

## I. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `pip install` 报 `qq-botpy-v2` 版本不满足 | Python 3.10 太旧 | 按 B 节兜底装 3.12 |
| `zhiliao` 起不来 | `.env.prod` 权限/路径、SECRET_KEY 不是 32 字节 | `journalctl -u zhiliao -n 100` |
| `ollama pull` 很慢 | 5M 带宽 | 正常，约 2 小时；看 `/tmp/ollama-pull.log` |
| `/parse` 返回 501 | 4b 不支持图片，或模型未加载 | 截图走端侧 OCR；`ollama ps` 确认常驻 |
| 首条解析很慢 | 模型冷加载 | 确认 `KEEP_ALIVE=24h` + 启动预热 |
| 公网访问不通 | 备案未下/防火墙未放行 | 先用 SSH 隧道；备案后开 80/443 |
| 备案被驳回 | 名称/域名/包名/指纹不一致 | 对照 F 节逐项核对 |

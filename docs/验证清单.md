## 4. 导出 / 导入（问题 11）

- [ ] 设置 → 数据 → 导出任务：
  - CSV：保存后打开确认表格、**不含原文**；
  - JSON：保存后确认含 `rawText`；

## 5. QQ 分享不可用时的降级（问题 3 / 4 / 5）

**现状**：华为 QQ 的系统分享面板只列 QQ 好友/群，不列第三方 App，这是 QQ 侧限制；代码里的 `sendData` 入口保留，但当前 QQ 走不到。

- [ ] **文本**：QQ 长按消息 → 复制或转发到「知了」机器人单聊 → 回到 App。
  - 预期：机器人回复「已收到…」，App 回到前台后自动打开「添加任务」半模态，原文带入并解析。
  - 前置：后端已重启、设备已绑定机器人、同步开关打开。
- [ ] **图片**：机器人单聊暂不接收图片转发；请在 App 里「＋ → 截图 → 从相册选择」完成，效果等同。
- [ ] **连续分享**：系统分享入口在 QQ 不可用，暂不验证；转发文本连续发两条时，App 打开最新一条并提示条数。

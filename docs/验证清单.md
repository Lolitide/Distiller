- [ ] **QQ 纯文本分享**：QQ 打开任意群聊 → 长按一条消息 → 分享 → 选择「知了」。

  - 预期：后一次覆盖前一次未保存草稿，重新解析，App 不崩溃；不出现两个半模态。

## 7. 后端接口（可直接 curl / PowerShell）

先取设备身份（注册一次）：

```powershell
$base = "http://127.0.0.1:8730/api/relay"
$reg = Invoke-RestMethod "$base/device/register" -Method Post -ContentType "application/json" -Body '{"name":"verify"}'
$h = @{ "x-device-id" = $reg.data.device_id; "x-device-token" = $reg.data.token }
```

- [ ] `/health`：`capabilities` 含 `candidates/parse/feedback/attachment/profile`；配置了推送服务账号时额外含 `push`。
- [ ] `/bind/reset`：`POST` 后 `bound=false`；旧绑定被清掉，重新生成码不会立刻读到旧 `bound=true`。
- [ ] `/my/prefs`：`POST {"skip_self":false}` 后 `GET /my/data` 的 `skip_self=false`；改回 `true` 生效。
- [ ] `/parse`：文本「明天下午三点交报告」→ `degraded` 字段存在；停掉 Ollama 后走规则路径时 `degraded=true`。
- [ ] 鉴权：不带或伪造 `x-device-token` → `unauthorized`（不是笼统 500）。
- [ ] 30 分钟窗口：`test_relay.py` 覆盖窗口过期后拉不到原文；手工可用 `/messages` 验证 `window_minutes=30`。
- [ ] 推送登记：`POST /push/token {"token":"fake"}` → `registered=true`，未配置服务账号时 `push_ready=false`。

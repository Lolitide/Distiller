## 一、结论

**本应用未集成任何第三方统计、广告、社交、推送聚合类 SDK**，不存在向第三方 SDK 提供个人信息的情形。

与外部发生数据交互的只有两类：

1. **华为系统能力（随 HarmonyOS 提供）**：Core Vision Kit（文字识别）、Core Speech Kit（语音识别）、Push Kit（推送令牌）、系统图片/文件选择器；
2. **开发者自建服务器**（`https://distiller.ltd`）：只接收路由信息，不接收任务正文与聊天原文。

其中 Core Vision Kit / Core Speech Kit 为**端侧处理**，图片与音频不出设备。

## 三、不共享的内容

- **任务正文不上传**：任务名称、备注、原文、步骤、地点、标签只在本机应用私有目录。
- **聊天原文不上传**：转发内容仅在服务端内存队列保留不超过 30 分钟，不写磁盘。
- **图片与音频不上传**：OCR 与语音识别均为端侧处理。
- 不出售、不转让、不用于广告投放、不做跨应用跟踪。

## 四、与开发者服务器的数据往来（非第三方共享）

| 数据项 | 用途 | 生命周期 |
| :-- | :-- | :-- |
| 设备标识、访问令牌 | 把结果推给正确的设备 | 删除服务端数据后清除 |
| QQ 绑定关系、群订阅列表 | 决定整理哪些群的消息 | 同上 |
| 采纳 / 忽略计数 | 减少不需要的候选（不含正文） | 同上 |
| Push 令牌 | 到点提醒 | 关闭通知或删除数据后清除 |
| 转发原文（内存） | 生成候选 | ≤ 30 分钟，不落盘 |

删除方式：App 内「设置 → 云端数据 → 删除服务端数据」。

## 1. 检测任务描述（可直接粘贴）

**完整版（约 350 字）**

```
知了 · 信息助手（包名 com.xjtu.distiller，版本 1.0.0 / 1000004）是一款 HarmonyOS 应用，把群里的通知整理成带时间、能提醒的个人待办。

功能：1) 任务清单（按天分组、六态状态、筛选、批量编辑、回收站、搜索）；2) 甘特视图；3) AI 解析：把一段文本交给服务端整理出「事项/时间/地点」，结果先进「待确认消息」，用户点「保留」后才成为任务；4) 提醒：系统代理提醒 + 自建日历账户兜底；5) 导出 CSV / JSON（带「AI生成」显式标识与 AIGC 隐式标识）、导入、清空本机数据。

账号：无账号体系、无登录页、无注册流程，打开即用。

数据边界：任务、备注、原文、步骤、草稿保存在本机应用私有目录；取得隐私授权后与开发者指定的服务器（https://distiller.ltd）通信，仅上传设备标识与访问令牌、Push 令牌、QQ 绑定关系与群订阅列表、采纳/忽略计数，以及当次提交用于解析的文本；转发内容在服务端仅在内存保留不超过 30 分钟、不落盘；语音识别全程在本机完成，音频不上传；截图优先在本机识别文字，本机识别不到时才把该张图片上传做文字提取，原图不保存。可在「设置 → 知了与隐私说明 → 隐私说明」随时撤回授权。

权限用途：网络（与服务器通信）、麦克风（本机语音转文字）、日历读写（写入日程与提醒）、通知与代理提醒（到点提醒）、系统文件选择器（仅读取用户选中的文件）。

第三方 SDK：未接入任何统计、广告、社交 SDK；仅使用系统 Kit（Core Vision Kit、Core Speech Kit、Push Kit）。

隐私政策：https://distiller.ltd/privacy
第三方信息共享清单：https://distiller.ltd/third-party-sharing

检测建议路径：冷启动（出现系统隐私弹窗）→ 任务列表 → 底部「+」→ 文本页签输入一段文字 → 点「AI 总结」观察「待确认消息」占位卡 → 打开任务详情查看底部「AI生成」标识 → 设置 → 数据 → 导出任务（CSV/JSON），可核对导出文件中的 AI 标识与 AIGC 字段。
```

知了 · 信息助手（com.xjtu.distiller，v1.0.0）是 HarmonyOS 校园待办应用，无账号体系。任务与原文存本机；同意隐私政策后仅向开发者指定服务器（https://distiller.ltd）上传设备标识、Push 令牌、绑定与订阅列表、反馈计数及当次解析文本；语音全程端侧不上传，截图仅在端侧识别失败时上传该图做文字提取；无第三方 SDK。权限：网络、麦克风、日历、通知。隐私政策 https://distiller.ltd/privacy ，共享清单 https://distiller.ltd/third-party-sharing

## 2. 隐私保护指引

**应用内路径（可作为截图证据）**

- 设置 → 知了与隐私说明 → **隐私说明**（可阅读全文、底部可「撤回隐私授权 / 重新授权」）
- 首次启动：由**系统标准隐私弹窗**（平台托管）取得同意，应用内不再自弹二次声明
- 另有独立页「**会离开本机的字段**」：逐项列出上传到服务端的字段白名单

**可直接上传的正文**

- 完整正文已单独成文：`docs/上架资质/隐私保护指引.md`（与 App 内九节正文逐条一致，并附「哪些字段会离开手机」）

**对外可访问链接（已上线，2026-11-11 实测 200）**

- 隐私政策：`https://distiller.ltd/privacy`
- 第三方信息共享清单：`https://distiller.ltd/third-party-sharing`
- 两页由后端 `server.py` 的 `PUBLIC_PAGES` 白名单 + Caddy `handle /privacy*`、`/third-party-sharing*` 提供，无鉴权、可无痕访问；页面文件在 `qqbot-backend/web/public/`
- 若平台允许填「应用内路径」，也可填：`设置 → 知了与隐私说明 → 隐私说明`

## 3. 第三方信息共享清单

> **线上链接**：`https://distiller.ltd/third-party-sharing`（已上线，可直接填到检测平台该栏）
>
> 完整成文版：`docs/上架资质/第三方信息共享清单.md`（含逐项表格、可关闭方式、华为隐私政策链接、待补项）。下面是可直接粘贴的简版：


```
一、第三方 SDK 情况
本应用未集成任何第三方统计、广告、社交、推送代理类 SDK；运行时依赖为系统 Kit 与系统组件。

二、与第三方的共享情况

| 名称 | 提供方 | 涉及信息 | 使用目的 | 触发时机 | 是否可关闭 |
| --- | --- | --- | --- | --- | --- |
| Push Kit（推送服务基础能力） | 华为 | 推送令牌（Push Token）、设备标识 | 由用户自建服务器在任务到点时下发提醒 | 取得隐私授权且应用启动时 | 是：撤回隐私授权或不用推送则不获取 |
| Core Vision Kit（文字识别） | 华为（端侧） | 用户当次选择的图片 | 识别截图中的文字，仅在本机处理 | 用户选择截图添加任务时 | 是：不使用截图入口即不触发 |
| Core Speech Kit（语音转文字） | 华为（端侧） | 用户当次录入的音频 | 识别语音内容，仅在本机处理 | 用户按住说话时 | 是：不使用录音入口即不触发 |
| 系统图片/文件选择器 | 华为（系统） | 用户主动选中的单个文件 | 读取用户选择的图片或导入 JSON | 用户点「选择文件/选择截图」时 | 是 |
| 开发者自建服务器（非第三方） | 开发者/使用者自行部署 | 设备标识与访问令牌、Push Token、QQ 绑定关系与群订阅列表、采纳/忽略计数 | 解析群消息生成候选、下发提醒 | 取得隐私授权后 | 是：撤回授权即停用 |

三、说明
· 图片（截图）与音频均在本机完成识别，不上传；
· 聊天原文仅在服务端内存停留不超过 30 分钟用于生成候选，不写磁盘、不回传；
· 应用不出售、不转让、不公开披露用户信息，不做广告投放与跨应用跟踪。
```

## 5. 测试账号登录

本应用**没有账号体系**：无登录页、无注册、无第三方登录，打开即进入任务列表。

建议填写：

- 账号登录：`无（应用不使用账号）`

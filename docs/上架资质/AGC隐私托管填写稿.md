# AGC 隐私托管（方案 A）填写稿

> 目标：不改服务器、不建网页，用 AGC 的**标准化隐私声明托管服务**产出一个公开隐私链接，同时满足检测平台的「隐私保护指引」与「第三方信息共享清单」两栏。
>
> 依据：官方 FAQ `FAQ/应用市场服务_AppGallery_Kit/隐私托管使用的场景和测试条件/faqs-appgallery-67` ——「应用和元服务上架应用市场必须提供隐私政策，隐私政策可以是链接地址，也可以使用隐私管理服务进行隐私托管」。
> 本应用代码已接 `@kit.AppGalleryKit` 的 `privacyManager`（`service/system/PrivacyConsent.ets`），即**已按托管模式接入**。

---

## 一、操作步骤（在 AGC 完成，约 10 分钟）

1. 打开 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入 **我的应用 → 知了 · 信息助手（com.xjtu.distiller）**。
2. 左侧 **应用信息**（或「分发 → 应用信息」）→ 找到 **隐私政策 / 隐私保护指引** 一项，确认「标准化隐私声明托管服务」处于**已开启**状态（应用里 `privacyManager` 能查到链路即说明已开）。
3. 在隐私声明编辑器里**整体替换**为下面第二节的纯文本正文（其中已包含「第三方信息共享清单」一节，一份链接就能同时应付检测平台两栏）。
4. 保存后，AGC 会生成隐私声明链接。取链接的两种方式：
   - AGC 页面直接复制（通常在隐私政策配置处显示「隐私链接 / 查看」）；
   - 或调用 `privacyManager.getAppPrivacyManageInfo()`，从返回的 `privacyInfo` 里取 `type = PRIVACY_STATEMENT_LINK(1)` 的链接。
5. 把该链接填到：
   - 检测平台「隐私保护指引」栏；
   - 检测平台「第三方信息共享清单」栏（清单是政策里的一节，同一链接即可，必要时在备注里注明「见隐私政策第三节」）；
   - 应用市场「隐私政策」配置项。
6. 更新日期一栏填今天的日期；开发者主体/联系方式按下面占位替换。

> 若 AGC 的托管编辑器不允许 Markdown：直接粘贴纯文本，不要带 `#`、`**`、表格线；第三节的清单改写成了「名称：…；用途：…；涉及信息：…」的句子，粘贴后仍然可读。

## 二、可直接粘贴的隐私声明正文（纯文本）

```
知了 · 信息助手 隐私保护指引  v1.0  更新日期：____年__月__日  生效日期：____年__月__日

【开发者信息】
应用名称：知了 · 信息助手    包名：com.xjtu.distiller    版本：1.0.0
开发者：____（待填）
联系方式：____（待填）
备案号：陕ICP备2026032183号

一、我们收集哪些信息，用来做什么
1. 只存在你的手机上、不会上传的信息：任务名称、备注、原文、步骤、截止时间与提醒时间、分类与标签、重要程度、你填写的地点、以及添加任务时的草稿。
2. 在你同意本政策后，应用会与开发者指定的服务器（地址固定为 https://distiller.ltd）通信，用于同步、解析与提醒。发往服务器的只有以下路由信息：
（1）设备标识与访问令牌：注册设备时生成，用于让服务器把结果推给正确的手机；
（2）QQ 绑定关系与群订阅列表：决定把哪些群的消息整理成候选；
（3）采纳 / 忽略计数：用于减少你不需要的候选，不包含任何任务正文；
（4）Push 令牌：用于服务端在到点时给你下发提醒；未开启推送则没有这一项。
3. 群消息原文：由服务器在内存中临时保留不超过 30 分钟，不写入磁盘、不会回传，仅用于生成你看到的候选与「原文对照」。
4. 我们不做：不收集通讯录、位置、应用安装列表；不做用户画像，不做广告投放，不做跨应用跟踪。

二、设备权限与用途
1. 网络（INTERNET）：与开发者指定的服务器通信（同步、解析、推送）。拒绝则云端相关功能不可用。
2. 麦克风（MICROPHONE）：仅在你按住说话时录音并转成文字。拒绝后仍可手动输入或粘贴文本。
3. 日历读取与写入（READ_CALENDAR / WRITE_CALENDAR）：把任务写成系统日程、并在到期前提醒。拒绝后任务仍保存在本机，只是不写日程。
4. 通知与代理提醒（PUBLISH_AGENT_REMINDER）：到点提醒与同步状态提示。拒绝后不会有提醒，任务本身不受影响。
5. 图片与文件：通过系统选择器让你挑截图或导入 JSON，只读取你选中的那一个文件。截图会先在手机本地识别文字；本地识别不到时，才会把这一张图片上传给开发者服务器做文字提取（不保存原图）。

三、第三方信息共享清单
本应用未集成任何第三方统计、广告、社交或推送聚合类 SDK，不存在向第三方 SDK 提供个人信息的情形。与外部发生数据交互的仅以下四类系统能力，以及开发者自建服务器：
1. Push Kit（推送服务基础能力，提供方：华为）：用于获取推送令牌，供服务端在任务到点时下发提醒；涉及推送令牌与设备标识；在同意隐私政策且应用启动时调用；撤回隐私授权或关闭通知后不再获取/上报；隐私政策见华为消费者业务隐私声明 https://consumer.huawei.com/cn/privacy/ 。
2. Core Vision Kit（文字识别，提供方：华为）：用于识别截图中的文字；优先在本机完成识别，本地识别不到时应用会把该张截图上传至开发者服务器做文字提取（原图不保存）；不使用截图入口即不触发；隐私政策同上。
3. Core Speech Kit（语音识别，提供方：华为）：用于把你当次录入的语音转成文字；仅在本机处理音频、不上传；不使用录音入口即不触发；隐私政策同上。
4. 系统图片 / 文件选择器（系统组件）：仅读取你在系统面板中主动选中的单个文件；不点选即不触发；隐私政策同上。
5. 开发者自建服务器（非第三方）：接收设备标识与访问令牌、QQ 绑定关系与群订阅列表、采纳/忽略计数、Push 令牌，用于生成候选与下发提醒；不接收任务正文与聊天原文；可在应用内「设置 → 云端数据 → 删除服务端数据」清除。

四、信息的存储与保护
1. 本机：保存在应用私有目录（首选项与文件），卸载应用即一并删除；导出的文件由你自己选择存放位置。
2. 服务器：仅限开发者指定的那台服务器（https://distiller.ltd）；群消息原文只驻留内存不超过 30 分钟，不落盘。
3. 传输：全部走 HTTPS。
4. 我们不会出售你的信息，不会用于广告，也不会与第三方共享。

五、第三方共享、转让与公开披露
1. 本应用没有接入任何第三方统计、广告或社交 SDK（逐项清单见第三节）。
2. 语音识别全程在本机完成，音频不上传；截图优先在本机识别文字，本地识别不到时才把该张图片上传至开发者服务器做文字提取，原图不保存。
3. 待办的自动整理（标题、时间、地点、类型、标签、步骤等）由开发者服务器调用大模型完成；其中聊天原文与图片音频不会上传，只有生成待办所必需的白名单字段会离开手机。
4. 除法律法规要求或你明确同意外，我们不共享、不转让、不公开披露你的信息。

六、关于人工智能生成内容
1. 本应用会对群消息文本做自动整理，生成待办标题、时间、地点、类型、标签、步骤等内容，这些内容由人工智能生成。
2. 生成结果仅供参考，可能存在偏差，请在保存前核对；应用内所有 AI 生成内容均标注「AI生成」。
3. 你导出的 CSV / JSON 文件同样带有「AI生成」标识与生成说明，并在文件元数据中写入 AIGC 隐式标识，便于识别内容来源。

七、你的权利
1. 查阅与更正：任务详情页可直接查看和修改每一项内容。
2. 删除：单条任务可删除；设置 → 数据 →「清空全部任务」可一次清空本机全部任务；设置 → 云端数据 →「删除服务端数据」可清除服务器上的记录。
3. 撤回授权：应用内「设置 → 知了与隐私说明 → 隐私说明」底部「撤回隐私授权」。撤回后 AI 与云相关能力（云端同步、服务端解析、语音转文字、OCR、实体抽取、推送上报）全部停用，本机基础功能仍然可用：手动增删改任务、本地提醒、通知、日历写入、导入导出。
4. 撤回后可随时重新授权，恢复后相关能力即刻可用。

八、未成年人保护
1. 本应用面向在校学生，不收集年龄、身份证号等身份信息，也不提供付费与社交功能。
2. 未满 14 周岁的用户请在监护人陪同下使用，并由监护人同意本政策。

九、本政策的更新
1. 政策如有变更，会更新顶部的「更新日期」，并在应用内提示你。
2. 涉及收集范围扩大的重大变更，会重新征求你的同意；不同意可继续使用本机基础功能。

十、联系我们
1. 本应用为校园实践项目，开发者联系方式见应用市场的应用详情页「开发者信息」。
2. 你也可以在应用的项目仓库中提交问题，我们会在 15 个工作日内答复。
```

## 三、提交前还要对齐的一处风险（建议一并处理）

当前打出来的包里 `pac.json` 是空的：

```json
{"dataProcess":[],"specialAPIs":[]}
```

AGC 会依据它生成**隐私标签**（官方：`开发指南/附录/pac_json5隐私清单文件/agc-pac`）。而应用实际会处理「设备标识 / Push 令牌」，标签写「无数据处理」很可能被判不一致。

建议在工程里补一个 `pac.json5`（我会按实际行为写好，例如：设备标识符 → 用于应用功能（提醒/同步）），重新打包后再提交。**这一步需要改代码并重新出包**，与托管填写可并行。

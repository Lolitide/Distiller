# AGC 隐私声明 · 改写版（对照现有线上原文）

> 用法：这份正文直接替换 AGC 托管编辑器里的现有声明（原文更新日期 2026.11.2）。
> 改写目标：**每一句都能在代码里找到对应实现**，避免检测平台比对时判「与实际行为不符」。

## 一、现有原文与实现的差异（先看这个）

| # | 原文写法 | 实际实现 | 风险 |
| :-- | :-- | :-- | :-- |
| 1 | 「任务名称、截止时间、地点等白名单字段会同步到你**自行配置**的转接服务」「该服务的地址由**你自己填写**、由你自行部署或选择」 | 服务器地址**写死在代码里**（`BackendConfig.ets:29` = `https://distiller.ltd`），设置页早已没有输入框 | 高：声明与行为不符，且与新版应用内政策冲突 |
| 2 | 「聊天原文、发送者、群号、图片与语音**不出手机**」 | ① 转发内容由 QQ 进服务器，原文在服务端**内存 ≤30 分钟**（不落盘）；② 手机端手动解析会把**你输入/粘贴的文本**发给服务器；③ 截图在端侧 OCR 失败时**回退上传该图**（`ManualParseService.parseImage` 第③步）；④ 语音确实全程端侧 | 高：截图上传这条最容易被检测抓到 |
| 3 | 「群消息原文…仅保存在你的设备本地，**不上传**」 | 同上：原文进服务端内存队列 30 分钟；且**自动群采集当前是关闭的**，群消息需你主动转发或手动解析 | 高：与「候选由服务端生成」自相矛盾 |
| 4 | 「只有你显式订阅某个群，该群的新消息才会进入解析」 | 当前版本 `QQBOT_GROUP_COLLECT=0`（默认关闭），订阅只决定「哪些群的转发会被接受」；不会自动抓群消息 | 中：夸大采集能力 |
| 5 | 「订阅的群列表…保存在本机」 | 绑定关系与订阅列表会**同步到服务端**（用于决定整理哪些群） | 中：与「云端数据 → 会离开本机的字段」页不一致 |
| 6 | 「撤销同意：设置 → **后端连接** → 删除服务端数据」；后文又写「设置 → **后端服务** → 删除服务端数据」 | 实际路径是 **设置 → 云端数据 → 删除服务端数据**；另有更直接的 **设置 → 知了与隐私说明 → 隐私说明 → 撤回隐私授权** | 中：路径不存在，用户按图索骥会失败 |
| 7 | 收集项写「录音」，但 `pac.json5` 未声明 Audio | 录音只在端侧转文字、不上传；`pac.json5` 现在声明的是 标识符 / 文字信息 / 图片或视频 | 中：声明两份口径不一致 |
| 8 | 更新日期 2026.11.2 / 生效日期 2026.10.27（且文中另有 2026.10.27） | — | 低：日期自相矛盾 |

## 二、改写后的正文（可直接整段替换）

```
关于知了 · 信息助手与隐私的声明
更新日期：2026.11.11
生效日期：2026.11.11

知了 · 信息助手 是由 谢忠宇（以下简称“我们”）为您提供的、用于把群聊消息整理成待办的校园信息管理应用。本隐私声明由我们为处理您的个人信息而制定。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

您可以通过访问隐私声明摘要快速了解应用收集、使用个人信息的目的、方式、范围。除上述主要功能外，我们在提供服务过程还涉及如下处理活动：

本应用只做一件事：把一段消息整理成带时间的待办。任务、备注、原文与偏好保存在您的手机上。本应用无账号体系，不需要注册登录；不采集通讯录、位置、通话记录与系统级设备标识（不含 IMEI、OAID、MAC）；不含广告，不向任何第三方出售或共享您的个人信息。

为完成“整理”这一步，应用会与开发者指定的服务器（地址固定为 https://distiller.ltd，不可由用户更改）通信：发往服务器的只有设备标识与访问令牌、QQ 绑定关系与群订阅列表、Push 令牌、采纳/忽略计数，以及您本次提交用于解析的文本；语音识别全程在本机完成，音频不上传；截图优先在本机识别文字，本机识别不到时才会把这一张图片上传给服务器做文字提取（原图不保存）。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 我们为您提供下述群消息转待办与任务管理功能。在您使用相关业务的过程中，我们会处理所必需的信息，以便履行我们的合同义务；若您不提供相关信息，会影响到您使用本应用的相关功能/服务。

为了实现应用功能，在获取您的同意后我们需要收集您的用户标识符（应用自建设备标识、访问令牌、推送令牌）、文字信息、图片或视频、日历、录音、应用设置信息、IP 地址。

上述信息用于把消息整理成待办，并在本机完成编辑、提醒与导出。其中：

· 任务内容、备注、原文、步骤、偏好设置保存在本机；
· 用于同步与提醒的路由字段（设备标识、绑定关系与订阅列表、Push 令牌、采纳/忽略计数）会发送至开发者指定的服务器；
· 需要解析时，您当次提交的文本会发送至该服务器；截图优先在本机识别文字，本机识别不到时才会把该张图片上传用于文字提取（原图不保存）；语音在本机转文字，音频不上传；
· 服务器不会长期保存聊天内容：转发内容仅在其内存队列中保留不超过 30 分钟，不写盘、不建库；
· 日历仅写入应用自建的本地日历账户作为提醒兜底，不读取您已有的日历事件；
· 自动群采集当前未开启，群消息需要您主动转发给机器人或手动粘贴/截图才会进入解析。

2. 设备权限调用

麦克风（使用麦克风）

用于语音录入，当您按住录音时采集语音并在本机完成转文字，音频不保存、不上传。

日历（读取日历信息、添加、移除或更改日历活动）

仅用于待办事项提醒，把待办写入应用自建的本地日历账户，完成后自动删除该日程；不读取、不上传您已有的其它日历事件。

网络

用于与开发者指定的服务器通信（同步、解析、提醒下发）。拒绝后云端相关功能不可用，本机功能不受影响。

通知与代理提醒

用于到点提醒与同步状态提示。拒绝后不会有提醒，任务本身不受影响。

3. 对未成年人的保护

3.1 我们非常重视对未成年人个人信息的保护，将严格按照国家法律法规要求对未成年人提供服务并对未成年人提供保护。如果您是未成年人，需要您的父母或其他监护人同意您使用本应用并同意相关应用的服务条款。父母或其他监护人也应采取适当的预防措施来保护未成年人，包括监督其对本应用的使用。

本应用面向高校学生群体，不面向儿童设计。

4. 管理您的个人信息

关于您的个人信息，您可以通过以下方式，行使查阅、复制、更正、删除等法定权利。

4.1 信息访问

您可以前往 设置 → 数据 → 导出任务，或直接在任务列表/任务详情查看您的任务内容与原文。

4.2 信息更正

当您需要更新您的个人信息，或发现我们处理您的个人信息有误时，您有权作出更正或更新。您可以前往任务详情页（点按任务名、步骤、属性、标签即可原地修改）修改您的任务内容。

4.3 信息删除

您可以前往任务详情页右上角删除单条任务；设置 → 数据 → 清空全部任务，删除本机全部任务与原文。

4.4 撤回同意

您可以随时在 设置 → 知了与隐私说明 → 隐私说明 页面底部点击「撤回隐私授权」。撤回后，云端同步、服务端解析、语音转文字、OCR、实体抽取与推送上报全部停用，本机基础功能（手动增删改任务、本地提醒、通知、日历写入、导入导出）仍然可用；您也可以随时在同一页面重新授权。

如需清除服务器上的记录，请前往 设置 → 云端数据 → 删除服务端数据。

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明中“如何联系我们”章节中所述方式与我们取得联系，并行使您的相关权利。

5. 信息存储地点及期限

5.1 固定存储期限：本机任务、备注、原文与设置保存至您主动删除或卸载应用为止。服务端候选与转发内容仅在内存中保留不超过 30 分钟滚动窗口，不落盘、不建库。

5.2 上述信息将会传输并保存至中国境内的服务器。

6. 信息处理边界与信息清单

本应用处理的是您主动提供或主动转发的内容。为最大限度降低风险，我们做了如下限制，并在此完整披露处理的信息范围：

一、信息清单

任务内容：您在应用内创建或编辑的任务名称、截止时间、地点、重复规则、重要程度、难度、类型、标签、备注。保存在您的设备本地。
文字信息：您手动输入、粘贴或转发给机器人的文本。用于生成待办；转发内容在服务端仅在内存保留不超过 30 分钟，不写盘。
图片与音频：您在「截图录入」「语音录入」中主动提供的图片与麦克风音频。语音仅在本机转文字、不上传；截图优先在本机识别文字，本机识别不到时才把该张图片上传至服务器做文字提取，原图不保存。
设备标识与访问令牌：应用首次连接服务器时在本机生成，用于设备配对与增量同步；另含推送服务下发的推送令牌（仅用于到点提醒）。不含 IMEI、OAID、MAC 等系统级标识。
偏好设置：主题色、卡片密度、提醒提前量保存在本机；QQ 绑定关系与群订阅列表、采纳/忽略计数会同步至服务器，用于决定整理哪些群的消息与减少不需要的候选。

二、四条硬边界

1. 任务正文（名称、备注、原文、步骤、地点、标签）只保存在您的手机本地，不上传服务器。
2. 语音全程在本机处理；音频不出设备、不上传、不留存。
3. 截图优先在本机识别文字；只有本机识别不到时，才把该张图片上传做文字提取，原图不做保存。
4. 自动群采集未开启：不读取您设备上的历史聊天记录，也不读取其他应用的通知栏消息；群消息需您主动转发或手动提交。

三、我们没有做的事

不采集通讯录、位置、通话记录、相册全量内容。
不做个性化推荐、不做广告投放、不做用户画像，不做跨应用跟踪。
不向任何第三方出售、出租或共享您的个人信息。

四、外部服务的说明

本应用需要一台服务器把消息整理成候选条目。该服务器由开发者部署，地址固定为 https://distiller.ltd（应用内不提供修改入口）。该服务仅接收上文「信息清单」中列出的路由字段与本次提交的解析文本；语音不出设备；截图仅在端侧识别失败时上传该张图片。

五、无账号体系

本应用不需要注册登录，因此不存在账号、密码、昵称、头像等信息，也不存在“注销账号”流程；卸载应用即终止全部数据处理。您可以在 设置 → 数据 → 清空全部任务 清除本机数据，在 设置 → 云端数据 → 删除服务端数据 清除服务端记录。

您可通过以下方式联系我们，并行使您的相关权利，我们会尽快回复。

邮箱：x2027235787@outlook.com
```

## 三、替换后要同步的地方

1. **应用内《隐私政策》**（`PrivacyPolicyText.ets`）已按同一口径改写，可直接对照本文第 1、6 节。

4. 若检测平台要求「第三方信息共享清单」独立链接：可复用本文链接，清单就是第 6 节（若你要更醒目，可把第 6 节改名为「第三方信息共享与处理边界」）。

## 9. 四、与第三方共享（如涉及）

```
本应用不与任何第三方出售、出租或共享您的个人信息，也不向其提供任务正文、聊天原文、图片与语音。

仅在以下系统能力下存在必要的数据交互：
1. 推送服务（华为 Push Kit）：应用获取推送令牌，用于服务端在任务到点时下发提醒；令牌不含任务内容，撤回隐私授权或关闭通知后不再获取与上报。

3. 系统图片/文件选择器：仅读取您在系统面板中主动选中的单个文件。

除法律法规要求或您明确同意外，我们不共享、不转让、不公开披露您的个人信息。
```

## 11. 六、管理您的个人信息

```
您可以通过以下方式行使查阅、复制、更正、删除等法定权利。

1. 信息访问：在任务列表 / 任务详情查看任务内容与原文；在「设置 → 数据 → 导出任务」导出 CSV / JSON。
2. 信息更正：在任务详情页点按任务名、步骤、属性、标签即可原地修改。
3. 信息删除：任务详情页右上角删除单条任务；「设置 → 数据 → 清空全部任务」删除本机全部任务与原文；「设置 → 云端数据 → 删除服务端数据」清除服务端记录。
4. 撤回授权：在「设置 → 知了与隐私说明 → 隐私说明」页面底部点击「撤回隐私授权」。撤回后云端同步、服务端解析、语音转文字、OCR、实体抽取与推送上报全部停用，本机基础功能（手动增删改任务、本地提醒、通知、日历写入、导入导出）仍然可用；可随时在同一页面重新授权。
5. 注销账号：不涉及。本应用无账号体系，不需要注册登录，不存在账号、密码、昵称、头像等信息，也不存在注销流程；卸载应用即终止全部数据处理。

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明“如何联系我们”章节所述方式与我们取得联系，并行使您的相关权利。
```

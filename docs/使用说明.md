# 使用说明

面向「想跑起来看一眼」和「想接到自己的后端」的人。功能边界与隐私约定见 [README](../README.md)。

---

## 1. 第一次跑起来

### 1.1 准备

| 项 | 要求 |
| :-- | :-- |
| 系统 | HarmonyOS 6.0.2(22) 手机 / 平板，或对应版本模拟器 |
| 工具 | [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（含 SDK）与 `devecocli` |
| 网络 | 只在「接后端」时需要；纯本机功能离线可用 |

### 1.2 构建

```bash
git clone <本仓库地址>
cd Distiller

devecocli build --modules entry
```

产物在 `entry/build/default/outputs/default/entry-default-unsigned.hap`。

> 产物名里带 `unsigned` 表示**未签名**：模拟器可直接安装，真机需要先在 DevEco Studio 里配置签名
> （`File → Project Structure → Signing Configs → 勾选 Automatically generate signature`）。

### 1.3 装到设备

```bash
devecocli device list                          # 先看有没有设备
devecocli run --module entry --device <sn>     # 多设备时必须显式指定 --device
```

失败时看日志：

```bash
devecocli log --level E --bundle-name com.xjtu.distiller
devecocli log --crash
```

## 2. 不接后端也能用的部分

应用启动后**不强制联网**。以下功能完全依赖本机数据：

- 新建任务（「＋」→ 文本/截图/录音入口 → 填名称 → 保存）
- 任务列表：按天分组、展开收起、筛选、勾选完成、批量删除
- 任务详情：名称、步骤、提醒/到期/重复、重要性/难度/类型/地点、标签、备注
- 搜索
- 设置：主题色、卡片密度、提醒提前量、清空本机任务

数据存在本机（`preferences`），杀掉进程重启后仍在。

## 3. 接入自己的后端（可选）

应用**不自带服务器地址**，也不会内置任何密钥——地址由使用者自己填。

### 3.1 后端需要提供的端点

| 方法 | 路径 | 用途 |
| :-- | :-- | :-- |
| GET | `/health` | 连通性检查，返回版本信息 |
| POST | `/device/register` | 注册设备，返回 `device_id` 与 `token` |
| POST | `/bind/code` | 取 6 位绑定码（在机器人侧输入完成配对） |
| GET | `/bind/status` | 查询绑定状态 |
| GET | `/groups` | 机器人所在的群列表 |
| POST | `/subscribe` / `/unsubscribe` | 订阅 / 退订某个群 |
| GET | `/api/relay/candidates?after=&limit=` | 增量拉取候选（`after` 是游标 `rev_seq`） |
| GET | `/api/relay/messages` | 拉取原文，用于详情页展示与溯源 |
| GET / DELETE | `/my/data` | 查看 / 删除服务端保存的我的数据 |
| POST | `/my/prefs` | 上报偏好 |
| POST | `/push/token` | 上报推送令牌 |
| POST | `/feedback` | 候选反馈 |

字段契约（哪些字段允许离开手机）见 README §6，实现见 `entry/src/main/ets/service/backend/`。

### 3.2 在 App 里配置

1. 底部胶囊右页签 → **设置** → 「后端服务」
2. 填入地址（形如 `http://<你的服务器>:8730`）→ 点「检查连通」
3. 成功后会显示服务端版本；若显示「无法连接」，先确认手机与服务器在同一网络、端口未被防火墙拦
4. 点「获取绑定码」→ 在机器人侧输入该码 → 回来看状态是否变为「已绑定」
5. 绑定后在「订阅的群」里打开要接收消息的群

> 改地址会清空旧的设备身份与游标（避免拿旧令牌请求新服务器），但**不会删除本机任务**。

### 3.3 换服务器 / 清数据

| 操作 | 结果 |
| :-- | :-- |
| 改服务器地址 | 清设备身份与游标，本机任务保留 |
| 我的数据 → 删除 | 清服务端保存的数据并断开手机端连接 |
| 设置 → 清空全部任务 | 只清本机任务，重启后仍为空 |

## 4. 常见问题

**Q：构建提示 `Will skip sign 'hos_hap'`？**
A：签名配置为空，属正常提示。产物未签名，模拟器可用；真机需在 DevEco 里配置自动签名后重新构建。

**Q：装到模拟器上「图片文字识别 / 语音」没反应？**
A：这两项能力**未实现**（`service/ai/` 仍是占位），且即便实现也不支持模拟器。

**Q：设了提醒时间但到点没提醒？**
A：提醒发布链路**尚未接入**（见 README §2「尚未实现」）。卡片上的铃铛开关目前只记录意图。

**Q：后端返回了候选，列表里却直接出现了任务？**
A：这是已知行为——确认页未实现，候选会直接落成本机任务（README §2 已标注）。

**Q：手机上改完任务，过几秒又变回原样？**
A：同步周期为 5 秒，轮询拉到的候选会覆盖同名字段。当前版本的已知限制，详见 README §2。

**Q：`设置 → 解析方式` 为什么是灰的？**
A：解析全部在服务端完成，客户端的「解析方式」已收敛为只读展示。

## 5. 开发约定（提 PR 前看一眼）

- 状态管理只用 **V2**（`@ComponentV2` / `@Local` / `@Param` / `@Event`），不与 V1 混用
- 分层固定 `页面 → ViewModel → service → repository`，页面不直接调系统能力
- 页面里不写裸色值 / 裸尺寸，一律取自 `utils/Theme.ets`
- AI 能力必须**动态 `import()`**，禁止顶层 import（模拟器上会闪退）
- 仓库不接收任何密钥、签名材料、`agconnect-services.json` 等凭据文件（已在 `.gitignore` 排除）

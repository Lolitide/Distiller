# 知了 · 信息助手 · 应用简介

> **一句话**：把群里刷过去就忘的通知，蒸成你自己那份「带时间的待办」。
>
> 名称「知了」取自动物知了（蝉）—— 夏天叫得最响、最容易被听见；英文名 **Distiller** 是「蒸馏」：把一段啰嗦的群消息，蒸出「什么事项、什么时候截止」。

- **平台**：HarmonyOS 6.0.2(22) 手机 / 平板
- **技术栈**：ArkTS / ArkUI（状态管理 V2）· 零第三方依赖
- **包名**：`com.xjtu.distiller` · 版本 1.0.0
- **备案号**：陕ICP备2026032183号

---

## 一、它解决什么问题

大学里的事，最先出现在群里：一门课一个群、一个社团还有好几个群，学生会、班级、实验室各不相同。

- 消息刷得太快，**没有重要性区分**，重要通知常被闲聊顶走；
- 「看到了但没记住」—— 直到截止前一晚才想起来；
- 记到备忘录里又**没有时间**，不会自己提醒。

知了只做一件事：**把你主动给它的一段消息，变成任务清单里带时间、能提醒的条目**。

数据流：群消息 / 转发的截图 → 后端大模型解析出「事项 / 时间 / 地点」→ 手机端拉取 → 落成本机任务（**先进「待确认消息」，你点保留才算数**）→ 到期提醒 / 写入日历。

## 二、核心功能

### 1. 收：从「一段消息」到「一条待办」

| 入口 | 说明 |
| --- | --- |
| QQ Bot 转发 | 把群消息、截图、文件转给机器人，服务端解析后推到 App |
| 应用内「＋」 | 文本 / 截图 / 录音三入口；「AI 总结」交给后端解析，**半模态立即收起**，后台在「待确认消息」里放一张「正在解析中…」占位卡，解析完原地变成正常待确认项 |
| 其他应用分享 | 注册 `ohos.want.action.sendData`，从微信/QQ 等直接分享纯文本、富文本、图片进来 |

- 解析失败**不丢消息**：卡片标题「解析失败」，第二行仍显示原文，右侧红色「重新解析」可原地重试；
- 解析途中不计入「待确认消息」组的未读红点，**解析完才 +1**；
- 解析结果永远先进「待确认」：保留 / 忽略由你决定，机器猜的字段（地点、对象）不擅自补全。

### 2. 管：任务列表与详情

- **按天分组**：未安排日期置顶，今天 / 明天 / 本周 / 更远，组可展开收起并记忆状态；
- **筛选**：全部 / 已完成 / 未完成 / 紧急；
- **六态状态机**：待确认 / 已确认 / 进行中 / 已完成 / 已过期 / 已删除；
- **批量编辑**：多选、批量完成、确认后删除；
- **任务详情**：名称原地编辑、步骤清单（可勾）、提醒 / 到期 / 重复、重要性 / 难度 / 类型 / 地点 / 链接 / 置信度、标签、备注、原文对照（只读可复制）；
- **搜索**：关键词搜索，空输入 / 无结果 / 有结果三态；
- **回收站**：忽略的消息与删除的任务都可恢复或彻底清空。

### 3. 看：板板（甘特视图）

按类型分轨的甘特图，可拖时间轴、拖表头拉条、显示当前时刻参考线，配任务摘要区 —— 一眼看清「这两周都有什么」。

### 4. 提醒：到点别错过

- 系统代理提醒发布 / 撤销，按「提前量」在到期前通知（到点 / 提前 5 / 15 / 30 分钟 / 1 小时）；
- 任务完成自动撤销提醒；
- 系统提醒不可用时，写入自建日历账户兜底，完成时清除；
- Push Kit 令牌注册与通道状态上报，用于服务端到点下发提醒。

### 5. 数据与隐私

- **本机即唯一真相**：任务、备注、原文、步骤、草稿只存在手机 `preferences`，不登录、不做账号；
- 云端可撤回：同意隐私政策后才会与开发者服务器通信，只发送**设备标识、绑定关系、反馈计数、Push 令牌**这类路由数据，**任务正文不上传**；可随时在隐私说明里撤回授权；
- 隐私政策为用户可见的独立页面，可随时撤回授权；「会离开本机的字段」单独一页列清；
- 导出 CSV / JSON 时带「AI生成」显式标识与文件元数据里的 **AIGC 隐式标识**（含伴随文件 `xxx.csv.aigc.json`），符合《人工智能生成合成内容标识办法》要求；
- 支持一键删除服务端数据、清空本机数据。

### 6. 个性化与外观

- M3 风格视觉，主题色三套、卡片密度两档，全部取自单一真值源 `utils/Theme.ets`；
- 自绘悬浮底部导航、与页面同色的状态栏；
- 首次启动三步引导（数据边界 → 权限 → 绑定 QQ Bot），设置页可「重新查看启动引导」；
- 「设置 → 知了与隐私说明」进入关于页：版本、隐私政策、重看引导、ICP 备案号（可点跳工信部）。

## 三、面向谁

| 人群 | 具体场景 |
| --- | --- |
| **在校大学生（首要）** | 课程作业 / 答辩通知、社团与学生会任务、比赛报名与截止、奖学金与宣讲会 |
| 班委 / 社团负责人 | 自己就是发通知的人：把写好的通知丢给 Bot，自动生成带时间的待办分发给自己的清单 |
| 信息密度高的多群用户 | 同时在水群、课程群、项目群，靠人肉记忆必然漏事 |
| 注重隐私的用户 | 不希望把全部聊天记录交给第三方 App 的用户：本机存储 + 只回传路由数据 |
| HarmonyOS 生态用户 | 想找一个纯 HarmonyOS 原生、不需要装安卓套壳工具的学生 |

不适合谁：需要多人协作、团队共享任务、跨设备实时同步的团队场景（本项目**明确不做账号与多设备同步**）。

## 四、价值

1. **降低「记住」的成本**：不需要改变用 QQ 的习惯，转发一条消息即可，剩下的交给解析与提醒。
2. **把「看到了」变成「做到了」**：带时间、能提醒、能写进系统日历，闭环到执行。
3. **可信的人机分工**：AI 只做「整理」，不做「决定」—— 结果先入待确认队列，用户可以改、可以忽略，缺失字段不猜。
4. **隐私优先的工程取舍**：不登录、不建账号、正文不出端，云端只承担「解析」与「路由」。
5. **可自建的开放性**：后端端点与字段契约公开（`docs/使用说明.md` §3），任何人都能接自己的服务器；不接后端时纯本机功能完整可用。
6. **真实场景验证过的准确率**：236 条真实语料评测，`qwen3.5:9b` 任务类型分类 90.7%、时间抽取 98.2%、地点抽取 94.5%、幻觉 1.3%（且幻觉输出会被字段校验拦下）。

---

> **边界声明**：本应用不做社交、不做群管理、不做账号与多设备同步；核心始终是「个人的、带时间的任务清单」。
